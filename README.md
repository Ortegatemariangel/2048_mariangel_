#  2048 - Versión 1

## Descripción

2048 es un juego 2D desarrollado con **HTML, CSS y JavaScript Vanilla**. El objetivo principal es combinar fichas que tienen el mismo número para obtener valores cada vez mayores hasta alcanzar la ficha **2048**.

El juego cuenta con un tablero de 4x4 y permite al jugador mover las fichas utilizando las teclas de dirección del teclado. Cada movimiento puede generar nuevas fichas y aumentar la puntuación.

Esta corresponde a la **Versión 1 (original)** del proyecto, en la cual se mantiene la mecánica básica del juego sin modificaciones relacionadas con la temática de San Gil. Esta versión sirve como base para realizar posteriormente la personalización y modificación del juego en la Versión 2
